What a Key Pass is

An Agent Key Pass is a transferable Pass, not a picture to hold and forget. One Pass is one key: it unlocks holder-only companion mint access, raffle entries and advisory votes. The same restrained art — a dark card, a thin gold key — is shared by all 444 Passes. The Agent ID gate is the value: the first 77 were free, but only for wallets that hold a Binance Agent ID — and they are gone. The paid mint is now open to every wallet.
