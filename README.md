# Agent Key Pass (AKEY)

444 transferable Agent ID passes on BNB Smart Chain.

- **Supply:** 444 total — 77 free (Agent ID holders only), 367 paid at $1.00
- **Mint:** 1 free per wallet, up to 3 paid per transaction
- **Contract:** `0x9eec890f05a7f60452574FF4Ae98F5Ae31B621B2` (BSC mainnet, verified on BscScan)
- **Royalties:** 5%
- **Live site:** https://agent-key-pass.pages.dev/

## How it works

A pass, not a picture collection: holding one gates the companion mint. Free passes are 1 per Agent ID wallet; paid passes open to everyone once the free ones are gone.

No floor price, returns, or token promises — just the collection and the live site.
