# Agent Key Pass (AKEY)

Agent Key Pass is a collection of 444 transferable passes on BSC mainnet. A pass is needed to mint the companion collection. Minting is gated by Binance Agent ID.

Contract: [0x9eec890f05a7f60452574FF4Ae98F5Ae31B621B2](https://bscscan.com/address/0x9eec890f05a7f60452574FF4Ae98F5Ae31B621B2)

Supply: 444 total. 77 free and 367 paid. The free mint is 1 per wallet and has sold out. Paid minting is open at ~0.00142 BNB ($1.00) per mint, up to 3 paid mints per transaction.

Minted: 78 as of 15 Nov 2026, including 1 paid mint. See the live count on BscScan: https://bscscan.com/token/0x9eec890f05a7f60452574FF4Ae98F5Ae31B621B2

No floor price, no returns, and no token promised.
